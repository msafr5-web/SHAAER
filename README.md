# منصة «شاعر»

المنصة الرقمية لتنظيم وحوكمة فن شعر المحاورة: التراخيص، والفعاليات، والتفاوض، والعقود الرقمية، والحضور الموثّق، والصرف بعد إثبات التنفيذ، والتقييم والتظلمات.

المرجع الوحيد للبناء: اللائحة التنفيذية والتنظيمية والتشغيلية الشاملة (الإصدار الأول 2025م)، ووثيقة متطلبات المنتج في [docs/PRD.pdf](docs/PRD.pdf)، وخطة إعادة البناء في [docs/PLAN.md](docs/PLAN.md).

## ما يغطيه هذا الإصدار

الإصدار الأول كما يحدده الملحق (س): رحلة الفعالية كاملة بخطواتها الثلاث عشرة في الملحق (هـ).

### اللوحات

| اللوحة | المسار | لمن |
|---|---|---|
| الموقع العام | `/` | الزوار: التعريف، جدول التراخيص، دليل المرخّصين، اللائحة، التحقق من الوثائق |
| الإدارة | `/admin` | إدارات المنصة: التراخيص، الفعاليات، الأطراف، الحالات، التظلمات، الدفتر، المعاملات، سجل النشاط |
| الجهة المنظمة | `/organizer` | إنشاء الفعاليات وإدارتها من الاعتماد إلى الإغلاق |
| الشاعر والأطراف المشاركة | `/poet` | الشاعر وقائد الصف وعضوه والمقيّم واللجان والإعلام |
| موقع الفعاليات (المضيف) | `/host` | المواقع وترخيصها والحجوزات |

## ما لم يُبنَ بعد، وسببه

- **الربط مع الجهات:** النفاذ الوطني، وبوابة الدفع، وحساب الضمان، والفوترة الإلكترونية، ووزارة التجارة، ووزارة الموارد البشرية. الدفع الحالي قيود تجريبية في الدفتر.
- **القواعد المعلّقة:** كل قاعدة عليها سؤال مفتوح لصاحب المبادرة تظهر في الواجهة بوسم «قيد الحسم»، ولا تُحصَّل غرامتها حتى تُحسم. القائمة في `/admin/parameters`.
- **المرحلتان 2 و3:** المسابقات، وسلّم العقوبات، والرعايات، والتصويت، والتكامل الآلي. التفاصيل في وثيقة المتطلبات.
- **محرك القواعد:** يحسب بالقيم الافتراضية من اللائحة في `src/lib/rules.ts`. وجدول المعاملات المؤرخة قائم، وربط الحساب بالقراءة منه هو الخطوة التالية.

## التشغيل المحلي

```bash
npm install
cp .env.example .env
npm run db:push
npm run db:seed
npm run dev        # http://localhost:3010
```

حسابات التجربة بنطاق `shaaer.test`: `admin` و`organizer` و`poet` و`row` و`evaluator` و`broadcast` و`host`. يظهر رمز الدخول على الشاشة في بيئة التطوير.

## الجودة

```bash
npm test                         # قواعد اللائحة بأرقام موادها، وحراس الشجرة
npm run typecheck
npx tsx scripts/smoke.ts         # كل الصفحات لكل الحسابات (والخادم يعمل)
npx tsx scripts/e2e-journey.ts   # رحلة الملحق (هـ) كاملة في متصفح Edge أو Chrome
```

الحراس في `tests/guards.test.ts`: لا شرطة طويلة، ولا لون Hex في الواجهات، ولا أصناف اتجاه فيزيائية، ولا مكتبة أيقونات خارجية، ولا خطوط جوجل بالرابط، ولا تعديل لسجل النشاط.

## الحزمة

Next.js 15 (App Router) و TypeScript و Prisma و Tailwind. قاعدة التطوير SQLite، والإنتاج PostgreSQL: انظر [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md).
