# النشر

## قاعدة البيانات: PostgreSQL

المنصة على PostgreSQL في التطوير والإنتاج معاً، والترحيلات في `prisma/migrations`. والإنتاج النهائي داخل المملكة (NFR-07).

- `DATABASE_URL`: اتصال التشغيل، ويقبل رابط المجمِّع (pooler).
- `DATABASE_URL_UNPOOLED`: اتصال مباشر تستعمله الترحيلات. إن لم يكن عندك مجمِّع فاجعله مثل الأول.

أوامر:

- `npm run db:push`: يطبّق الترحيلات (`prisma migrate deploy`).
- `npm run db:migrate`: ينشئ ترحيلاً جديداً بعد تعديل المخطط (تطوير فقط).
- `npm run db:seed`: أنواع التراخيص والمعاملات والسياسات دائماً، والبيانات التجريبية خارج الإنتاج أو بـ `SEED_DEMO=true`. البذرة آمنة للتكرار.

## Vercel (نسخة عرض)

البناء على Vercel يشغّل `npm run vercel-build`: توليد عميل Prisma، ثم تطبيق الترحيلات، ثم البذرة، ثم بناء Next.js.

1. **Storage** في المشروع: أنشئ قاعدة Postgres (Neon) واربطها بالمشروع لكل البيئات، فيُضاف `DATABASE_URL` و`DATABASE_URL_UNPOOLED` تلقائياً.
2. **Settings ثم Environment Variables**:

| المتغير | القيمة |
|---|---|
| `SESSION_SECRET` | 32 حرفاً عشوائياً على الأقل، ويرفض الخادم العمل دونه |
| `APP_URL` | عنوان النشر، مثل `https://shaaer.vercel.app` |
| `SEED_DEMO` | `true` لإنشاء حسابات التجربة |
| `AUTH_DEMO_SHOW_CODE` | `true` ليظهر رمز الدخول على الشاشة لعدم وجود مزود بريد. أي أحد يدخل بأي بريد، فلا يُستعمل مع بيانات حقيقية |

3. **Deployments**: أعد النشر (Redeploy).

ملاحظة: Vercel لا يستضيف داخل المملكة، فهو للعرض والتجربة لا للإطلاق (NFR-07).

## متغيرات الإنتاج النهائي

| المتغير | الإنتاج |
|---|---|
| `DATABASE_URL` و`DATABASE_URL_UNPOOLED` | PostgreSQL داخل المملكة |
| `APP_URL` | العنوان العام، لروابط رموز QR |
| `SESSION_SECRET` | 32 حرفاً عشوائياً على الأقل |
| `AUTH_DEV_SHOW_CODE` و`AUTH_DEMO_SHOW_CODE` | `false` |
| `SEED_DEMO` | `false` |

## قبل الإطلاق العام

- ربط النفاذ الوطني بدل رمز البريد (المادة 62).
- ربط بوابة الدفع وحساب الضمان بعد حسم السؤال ب1 والاستشارة النظامية.
- ربط الفوترة الإلكترونية مع هيئة الزكاة والضريبة والجمارك.
- حسم الأسئلة المعلّقة في `/admin/parameters`.
- إيقاف البيانات التجريبية (`SEED_DEMO=false`) وعرض الرمز.

## التشغيل

`npm run build` ثم `npm start` (المنفذ 3010)، خلف وكيل عكسي بشهادة TLS. ولا يُشغَّل البناء والخادم التطويري على مجلد `.next` نفسه في وقت واحد.
