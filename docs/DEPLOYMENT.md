# النشر

## قاعدة البيانات: من SQLite إلى PostgreSQL

التطوير المحلي على SQLite لأن الخادم المحلي لا يحتاج إعداداً. والإنتاج على PostgreSQL، داخل المملكة (NFR-07).

المخطط لا يستعمل أنواع Enum ولا JSON خاصة بمزوّد، فالتبديل سطر واحد:

1. في `prisma/schema.prisma` غيّر `provider = "sqlite"` إلى `provider = "postgresql"`.
2. اضبط `DATABASE_URL` على PostgreSQL.
3. أنشئ الترحيل الأول: `npx prisma migrate dev --name init` في بيئة اختبار، ثم `npx prisma migrate deploy` في الإنتاج.
4. `npm run db:seed` لأنواع التراخيص والمعاملات والسياسات. البيانات التجريبية تُنشأ فقط إن كانت قاعدة المستخدمين فارغة، فاحذف قسمها من البذرة قبل الإنتاج.

## متغيرات البيئة

| المتغير | الإنتاج |
|---|---|
| `DATABASE_URL` | PostgreSQL |
| `APP_URL` | العنوان العام، لروابط رموز QR |
| `SESSION_SECRET` | 32 حرفاً عشوائياً على الأقل، ويرفض الخادم العمل دونه |
| `AUTH_DEV_SHOW_CODE` | `false` (لا يُعرض الرمز إلا في التطوير أصلاً) |

## قبل الإطلاق العام

- ربط النفاذ الوطني بدل رمز البريد (المادة 62).
- ربط بوابة الدفع وحساب الضمان بعد حسم السؤال ب1 والاستشارة النظامية.
- ربط الفوترة الإلكترونية مع هيئة الزكاة والضريبة والجمارك.
- حسم الأسئلة المعلّقة في `/admin/parameters`.
- حذف البيانات التجريبية من البذرة.

## التشغيل

`npm run build` ثم `npm start` (المنفذ 3010)، خلف وكيل عكسي بشهادة TLS. ولا يُشغَّل البناء والخادم التطويري على مجلد `.next` نفسه في وقت واحد.
